# Home Assistant용 Hyundai Kia Genesis Developers

**한국어** | [English](README.en.md)

![Hyundai Kia Genesis Developers](custom_components/hyundai_kia_developers/brand/logo.png)

대한민국 현대, 기아 및 제네시스 개발자 API에서 차량 정보를 조회하는 비공식 Home
Assistant 통합 구성요소입니다. 여러 계정과 차량을 지원하고, 접근이 승인된 차량을
자동으로 검색하며, 가능한 경우 인증을 자동으로 갱신합니다. 차량 조회만 지원하며
문 잠금, 공조와 같은 원격 제어 기능은 제공하지 않습니다.

> 이 통합 구성요소는 대한민국 개발자 서비스만 지원합니다. 다른 지역의 계정,
> 프로젝트 및 차량은 호환되지 않습니다.

## 요구 사항

- Home Assistant 2026.7.0 이상
- HACS
- 대한민국 현대, 기아 또는 제네시스 개발자 회원 및 프로젝트
- 본인 Bluelink, Kia Connect 또는 Genesis Connected Services 계정에 등록된 차량

각 브랜드의 개발자 회원과 프로젝트를 별도로 만들어야 하며, 차량의 커넥티드
서비스 계약자 계정이 필요합니다.

> **본인 명의 차량이라도 가족 등 다른 사람에게 공유 중이면 차주 계정의 등록 가능한
> 차량 목록에 표시되지 않습니다.** 다른 사람에게 공유받은 차량도 제외됩니다.
> 설치 전에 제조사 앱의 차량 공유 상태를 확인하세요.

공유를 해제하기로 했다면 제조사 앱에서 해제한 뒤 새 인증으로 차량 목록을 다시
확인하세요. 공유를 해제하면 공유받은 사람의 앱 접근도 종료됩니다. 자세한 내용은
[차량 공유와 등록 안내](docs/troubleshooting.md#제조사-화면에-등록된-차량이-없습니다가-표시될-때)를 확인하세요.

## HACS로 설치

1. HACS에서 **Custom repositories**를 엽니다.
2. `https://github.com/mahlernim/hyundai-kia-developers-ha`를
   **Integration** 유형으로 추가합니다.
3. **Hyundai Kia Genesis Developers**를 설치하고 Home Assistant를 재시작합니다.

## 개발자 프로젝트 준비

[한국어 개발자 프로젝트 등록 안내](docs/developer-setup.md)에 따라 프로젝트 생성,
차량 등록, URL 세 개 저장, Client ID와 Client Secret 확인을 순서대로 진행하세요.

세 브랜드 모두 다음 값을 사용합니다.

| 설정 항목 | 값 |
| --- | --- |
| 계정 API Redirect URL | `https://example.com/redirect` |
| 데이터 API Redirect URL | `https://example.com/redirect` |
| 데이터 API Callback URL | `https://example.com/callback` |

각 입력란 오른쪽의 **저장** 버튼을 따로 눌러야 합니다. 한 번만 누르면 나머지 값은
저장되지 않습니다.

## Home Assistant에 계정과 차량 추가

1. **설정 → 기기 및 서비스 → 통합 구성요소 추가**에서
   **Hyundai Kia Genesis Developers**를 선택합니다.
2. Hyundai, Kia 또는 Genesis를 선택합니다.
3. 프로젝트의 Client ID와 Client Secret을 입력합니다.
4. 인증 링크를 열고 커넥티드 카 계정으로 로그인한 뒤 접근을 승인합니다.
5. 등록한 리디렉션 주소에 도착하면 `code`와 `state`가 포함된 전체 URL을 복사해
   Home Assistant에 붙여 넣습니다. 이 두 값이 있는 최종 주소에 도착한 경우에만
   `example.com`의 페이지 오류를 무시할 수 있습니다.
6. 검색된 차량을 선택하고 이름을 확인합니다.

리디렉션 URL에는 일회용 인증 코드가 포함됩니다. 로그, 스크린샷, 메시지 또는
이슈에 공유하지 마세요.

## 엔티티

| 엔티티 | 제공 대상 | 기본 상태 |
| --- | --- | --- |
| 주행 가능 거리 | 모든 차량 | 활성화 |
| 누적 주행 거리 | 모든 차량 | 활성화 |
| 커넥티드 서비스 무료 기간 남은 일수 | API가 무료 서비스 종료일을 제공하는 경우 | 활성화 |
| EV 배터리 잔량 및 충전 상태 | EV 및 PHEV | 활성화 |
| 통합 주행 가능 거리 | API가 값을 제공하는 PHEV | 활성화 |
| 충전 케이블, 충전기 유형, 목표 충전량 및 남은 충전 시간 | EV 및 PHEV | 비활성화 |
| 통합 차량 경고 | 모든 차량 | 활성화 |
| 개별 연료, 타이어, 램프, 스마트키 배터리, 워셔액, 브레이크액 및 엔진오일 경고 | 차량이 제공하는 경우 | 비활성화 |
| 차량 데이터 새로고침 | 구성된 각 계정 | 활성화 |

비활성화된 엔티티는 Home Assistant의 차량 장치 페이지에서 활성화할 수 있습니다.
차량 정보는 기본 60분마다 갱신되며 통합 구성요소 옵션에서 30분부터 1440분까지
변경할 수 있습니다.

통합 차량 경고는 사용 가능한 경고 API 중 하나라도 문제를 보고하면 켜집니다.
`warning_count`, `active_warnings`, `unavailable_warnings` 속성은 자동화에 사용할 수
있는 고정 식별자로 세부 정보를 제공합니다. 이 엔티티를 조회할 때 갱신 주기마다
차량 한 대당 API 요청 7건이 필요합니다. 개별 경고 엔티티를 활성화해도 같은 요청을
재사용합니다. 일부 개별 경고 요청이 실패하면 통합 차량 경고는 사용 가능한 결과를
계속 사용하고 실패한 식별자를 `unavailable_warnings`에 표시합니다.

커넥티드 서비스 센서는 제공사가 반환한 무료 서비스 종료일까지 남은 일수를
표시합니다. `subscription_date`, `free_service_end_date`, `expired` 속성은 자동화에
사용할 수 있는 고정 이름으로 제공됩니다. 종료일이 지나면 상태는 0으로 유지됩니다.
API가 유효한 무료 서비스 종료일을 제공하지 않으면 센서는 사용할 수 없습니다. 이
센서를 조회할 때 갱신 주기마다 활성화된 차량 한 대당 API 요청 1건이 추가됩니다.

계정 단위 **차량 데이터 새로고침** 버튼을 누르면 해당 계정의 모든 차량에서 현재
활성화된 API를 즉시 다시 조회합니다. 따라서 버튼을 누를 때마다 정기 갱신과 같은
API 요청이 실행됩니다.

## 계정과 여러 차량

계정 이름은 `Kia`, `Hyundai`, `Genesis`처럼 자동 생성됩니다. 같은 계정의 다른
접근이 승인된 차량은 **차량 추가**로 추가합니다. 브랜드마다 별도 계정으로 추가하세요.

## 문제 해결

[단계별 문제 해결 안내](docs/troubleshooting.md)에서 다음 상황을 구분하여 확인하세요.

- 제조사 로그인 화면의 **등록된 차량이 없습니다**
- 인증 후 Home Assistant가 받은 빈 차량 목록 또는 제조사 오류 코드
- 요청 한도, 재인증 실패, 일부 차량의 접근 권한 누락
- 설정 후 데이터가 갱신되지 않거나 엔티티가 없는 경우

제조사 화면에서 진행할 수 없다면 인증 화면의 도움말 항목을 선택하세요. 오류가
발생한 경우에는 복구 화면에서 다시 시도하거나 새로 로그인할 수 있습니다. 기존에
설정한 계정과 차량은 재인증 검증 실패만으로 변경되거나 삭제되지 않습니다.
