# 설정 및 차량 조회 문제 해결

**한국어** | [English](troubleshooting.en.md)

같은 ‘차량 없음’ 안내라도 표시된 단계에 따라 확인할 항목이 다릅니다. 먼저 제조사
웹페이지에서 멈췄는지, 로그인 후 Home Assistant에서 오류가 발생했는지 확인하세요.

## 제조사 화면에 ‘등록된 차량이 없습니다’가 표시될 때

이 화면은 Home Assistant가 인증 코드나 차량 목록을 받기 전의 단계입니다.
통합 구성요소가 제조사 화면의 목록을 바꾸거나 차량을 추가할 수는 없습니다.

**먼저 본인 명의 차량을 가족 등 다른 사람에게 공유 중인지 확인하세요.** 차주이자
커넥티드 서비스 계약자여도 차량 공유를 사용하면 등록 가능한 목록에 차량이
표시되지 않습니다. 다른 사람에게 공유받은 차량도 제외됩니다. 이는 제조사의
[현대](https://developers.hyundai.com/web/v1/hyundai/guide_api),
[기아](https://developers.kia.com/web/v1/kia/guide_api),
[제네시스](https://developers.genesis.com/web/v1/genesis/guide_api) API 안내에 명시된
차량 접근 동의 단계의 제한입니다.

1. Bluelink, Kia Connect 또는 MY GENESIS 등 해당 제조사 앱에서 **차량 공유** 상태를
   확인합니다. 가족이 사용하는 공유 계정도 포함됩니다.
2. 공유를 해제하기로 했다면 해당 앱에서 해제합니다. 공유받은 사람의 앱 접근도
   종료됩니다. 공유를 유지하려면 이 차량의 등록을 진행할 수 없습니다.
3. 선택한 브랜드와 Client ID가 차량을 등록한 개발자 프로젝트의 값인지 확인합니다.
4. **내차량등록**에서 등록과 약관 동의를 마치고 **활성화** 상태인지 확인합니다.
5. Home Assistant에서 **새로 로그인**을 선택하여 새 인증 링크를 열고 차량 목록을
   다시 확인합니다. 해당 차량의 커넥티드 서비스 계약자 계정으로 로그인하세요.
   다른 계정의 로그인 상태가 남아 있다면 제조사에서 로그아웃하거나 비공개 창을
   사용합니다.

공유 해제 후 목록에 반영되는 시간과, 등록 후 공유를 다시 켰을 때 연동이 유지되는지는
확인되지 않았습니다. 일시적인 공유 해제만으로 계속 사용할 수 있다고 가정하지 마세요.

위 조건이 맞아도 계속 발생하면 제조사 개발자 서비스의 문의 채널에서 프로젝트의
차량 연결 및 계정 상태 확인을 요청하세요. Home Assistant 버전과 관계없이 제조사
인증 화면에서 발생하는 문제인지 함께 설명하면 도움이 됩니다.

**Service Agreement**는 액세스 토큰을 사용하여 Data API 제공 동의를 받는 별도
절차입니다. 인증 코드가 발급되기 전의 빈 차량 목록을 해결하는 우회 방법으로
문서화되어 있지 않습니다. 이 통합 구성요소는 해당 별도 동의 화면을 자동으로 열지
않습니다. 프로젝트 삭제나 차량 재등록을 일반적인 해결 방법으로 권장하지 않습니다.

Home Assistant의 인증 화면에서 URL을 비워 두고 **제조사 로그인 또는 차량 동의
화면에서 진행할 수 없음**을 선택하면 도움말과 설정 진단 요약을 볼 수 있습니다.
이 선택은 사용자가 도움을 요청했다는 뜻이며, 제조사 화면의 오류를 자동으로
감지했다는 뜻은 아닙니다.

## Home Assistant에서 오류가 발생할 때

| 표시된 내용 | 의미와 다음 작업 |
| --- | --- |
| 리디렉션 주소 또는 인증 코드 오류 | 등록한 주소와 `code`, `state`가 있는 최종 URL인지 확인합니다. 다른 설정 창에서 만든 URL은 사용할 수 없습니다. |
| 인증 코드 교환 실패 | 코드는 한 번만 사용할 수 있습니다. **새로 로그인**을 선택하여 새 링크에서 인증을 시작합니다. |
| 빈 차량 목록 | 로그인 후 API가 빈 목록을 반환했습니다. 본인 차량을 타인에게 공유 중인지 먼저 확인한 뒤 프로젝트의 차량 활성화와 접근 동의를 확인합니다. 빈 목록만으로 다른 계정이라고 단정할 수는 없습니다. |
| 오류 `4045` | 차량 목록 또는 데이터가 제공되지 않았습니다. 성공한 빈 목록과 구별하여 처리합니다. |
| 오류 `4046` | 제조사가 등록된 차량을 찾지 못했습니다. 해당 프로젝트의 차량 등록과 활성화 상태를 확인합니다. |
| 오류 `5005` | Data API 제공 동의가 필요합니다. 제조사의 Service Agreement 안내에 따라 동의를 완료한 뒤 다시 시도합니다. |
| 오류 `5006` | 프로젝트의 해당 API 사용 권한을 확인합니다. |
| 요청 한도 도달 | 안내된 시간을 기다린 뒤 다시 시도합니다. 서버가 대기 시간을 주지 않으면 60초를 적용합니다. |
| 기존 차량 일부가 새 목록에 없음 | 다시 로그인하거나 현재 권한으로 계속할 수 있습니다. 기존 차량 설정은 유지되지만 빠진 차량의 조회는 실패할 수 있습니다. |

복구 화면의 **다시 시도**는 현재 토큰으로 실패한 조회를 반복합니다. **새로 로그인**은
새 인증 절차를 시작합니다. 잘못된 Client ID, Client Secret 또는 Redirect URL을
입력했다면 설정을 다시 시작하거나 기존 계정의 **재구성**을 사용하세요.

**Car ID 직접 입력**은 차량 목록이 비어 있거나 오류 `4045`로 제공되지 않고, 제조사
API에서 받은 Car ID를 알고 있을 때만 사용할 수 있습니다. Car ID는 차대번호(VIN)가
아닙니다. 이 방법으로 접근 권한이나 동의를 우회할 수 없으며, 차량 데이터가 확인되지
않으면 등록하지 않습니다. 자동 검색된 차량은 일부 데이터가 아직 없어도 등록할 수 있습니다.

## 설정 후 값이 갱신되지 않을 때

제조사 API는 차량이 마지막으로 전송한 데이터를 제공할 수 있습니다. 정기 조회나
**차량 데이터 새로고침** 버튼이 차량에 새로운 데이터를 전송하도록 강제하는 것은
아닙니다. 반복 새로고침은 API 사용량을 늘립니다.

일부 엔티티는 기본적으로 비활성화되어 있거나 차량이 해당 데이터를 제공하지 않을
수 있습니다. [엔티티 안내](../README.md#엔티티)에서 제공 조건을 확인하세요.

## 문제를 보고할 때

[버그 신고 양식](https://github.com/mahlernim/hyundai-kia-developers-ha/issues/new?template=bug_report.yml)에
통합 구성요소 버전, Home Assistant 버전, 브랜드, 실패한 단계와 재현 방법을 적어 주세요.
설정 복구 화면의 진단 요약은 계정을 추가하기 전에도 복사할 수 있습니다.
`unknown`은 해당 정보가 없거나 공개용 요약에 포함하지 않았다는 뜻입니다.

이미 설정한 계정은 Home Assistant에서 진단 정보를 다운로드할 수 있습니다.
공유 전 내용을 확인하고 Client ID, Client Secret, 인증 코드와 토큰, 전체 리디렉션 URL,
Car ID, VIN과 개인정보를 포함하지 마세요. 제조사 문의에 필요한 계정 식별 정보는
제조사의 비공개 지원 채널로만 전달하세요.
